## 🍇 About Me

**데이터와 AI로 문제를 해결하고, 반복 업무를 자동화하는 데이터 분석가 류소현**입니다.

- 💼 **Wisenut**에서 Data Analyst로 일하고 있습니다.
- 📊 공공·산업 분야의 **데이터 분석** 및 **AX 데이터 구축** 프로젝트를 수행하고 있습니다.
- 🤖 Python·SQL을 활용한 데이터 처리부터 **LLM 및 프롬프트 엔지니어링** 기반 데이터 구축·자동화까지 다양한 업무를 수행합니다.
- 🛠️ 반복적이고 번거로운 작업은 직접 자동화 도구를 만들어 해결합니다. 채용 공고 수집, AI 뉴스 브리핑, 영상 요약 등이 대표적입니다.
